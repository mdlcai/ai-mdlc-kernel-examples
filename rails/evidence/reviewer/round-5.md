## Findings

No BLOCKER or MAJOR.

### M1 — MINOR — the desktop media gate uses px where Tailwind's `md` uses rem

`console-shell.tsx:19` uses `const DESKTOP = '(min-width: 768px)'`, but the column and the Menu button switch at Tailwind's `md`, which is `48rem` (`tailwindcss/theme.css:328`). Media-query rem follows the user's default font-size setting, not 16px. With Chrome set to "Small" (12px), `md` starts at 576px. From 576 to 767px the sidebar column is visible but empty because `desktop` is false, the Menu button is `md:hidden`, and the header brand link is `md:hidden`. The console has no navigation in that band. With a larger default font size the mismatch goes the other way (Sidebar rendered but hidden while the drawer is available), which is harmless. Fix: `const DESKTOP = '(width >= 48rem)'` (or `(min-width: 48rem)`), so the gate matches the CSS breakpoint exactly.

### M2 — MINOR — the "Scan to pay" roadmap card is not in SPEC

`page.tsx:57-62` publicly announces "instant, QR-initiated bank payments through the same API, via licensed partners". SPEC.md does not mention real-time or QR account payments, not even as a Non-Goal (`SPEC.md:21-31`). The card is honest about scope ("Not part of v1", deferred badge), so this is a SPEC-alignment gap rather than a false capability claim. The commit cites ADR-051, which this review was not allowed to read. Fix: add the item to SPEC §1 Non-Goals as a deferred, partner-only rail, so the marketing claim traces to SPEC like the ACH and Bitcoin card does.

### M3 — MINOR — the network grid now orphans the seventh card

`marketing.css:216-221` forces three columns at 1024px and up "so the six network cards never wrap 5+1". With seven nodes it renders 3+3+1, and the comment is stale. Fix: rebalance the layout (for example, let the last card span the row or use a 4+3 layout), or merge the card into an existing deferred node and update the comment.

### A1 — ADVISORY — same-key responses can arrive out of order (pre-existing)

`useReport` keys state by query, not by request. If a realtime reload (`kpis.tsx:44-47`) and an earlier fetch for the same key are both in flight, whichever resolves last wins, even if it is older. The transition does not change this. A request sequence number in `settle` would close it.

### A2 — ADVISORY — intrinsic-size estimates

`auto 900px` (landing) and `auto 280px` (dashboard panels) are first-visit estimates. If a real height differs a lot, the scrollbar jumps once while scrolling. That is not CLS because it happens off-screen. Consider measuring the typical rendered heights at 375px and 1280px and using those.

### A3 — ADVISORY — the CHANGELOG is slightly loose

- "The session and report renders run as React transitions": only the initial session load is a transition. `refresh()` is not.
- The dashboard chart and breakdown panels also gained `content-visibility`. The commit message says so, but the CHANGELOG does not.
- "Built once rather than once per cell": money formatters are built once per currency.

### A4 — ADVISORY — coverage gaps

Add the following:

- A unit test that the initial session settle redirects on 401 and shows children only after a session.
- A test that the drawer renders its nav only when open.
- A formatter test with mixed-case and repeated currency codes, to pin the cache keying.

### A5 — ADVISORY — no spec runs Enqueue then Deliver on the real clock

Now every Enqueue-to-Deliver example runs under a frozen clock or passes `now:` explicitly. Nothing exercises the production default path, where Enqueue stamps the real time and `Deliver.call(id)` or `DeliverPendingEmailsJob.perform_now(id)` runs without `now:`. Add one unfrozen example (`email = Emails::Enqueue.call(...)`, then `expect(DeliverPendingEmailsJob.perform_now(email.id)).to eq(email.id => :sent)`) to pin the behaviour this commit relies on. Separately, any spec that pins `now` to a fixed date while production code reads `Time.current` will break the same way once that date passes. The job spec avoids this because it builds its rows from the pinned `now` directly.
