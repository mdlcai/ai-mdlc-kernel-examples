I found no critical, high, medium or low issues, and four infos. The advisory is the standing one: there is no tooling for secret detection or TypeScript SAST.

- **Tenancy holds.** `orb` adds no route. It goes through the existing `POST /jobs` `submit`, which runs inside `tenant_session` with tenant-filtered, RLS-backed project lookups. A viewer gets 403 and another tenant's project returns 404, not 403 (tested). A circuitId with kind orb returns 422 `circuitId` UNSUPPORTED before any lookup (tested). `Member`, the admin cap on API keys and the 25-key limit are untouched.
- **Validation is strict.** I sent 60 adversarial `params` through `validate_params("orb", …)`. NaN, ±inf, bools, strings, null, lists, floats in integer fields, 400-digit integers, unknown and snake_case keys, and every bound just outside the SPEC §3 limits each return one 422 with the right `params.<name>` path and code. None of them reaches a 500. The six real-valued fields are normalised to `float`. The evolution `rngSeed` is `StrictInt | None` with ge 0 and le 2^32−1, so it rejects 2^32, −1, True, "7", 7.0 and 10^19. One cosmetic issue: a 422 reports in two phases (P7-3).
- **Resource bounds hold with a wide margin.** I ran 38 corner configurations, each in a cold, single-threaded process the way the job child runs. The heaviest is **qubits 3 with budget 2048** (not qubits 8): **15.0 s CPU / 16.2 s wall**, 73 MiB peak RSS (tracemalloc 32 MiB), and a **236 KB** result. That is 12 % of the 120 s timeout and RLIMIT_CPU, about 10 % of RLIMIT_AS 768 MB, and matches the "~15 s and ~260 KB at the limits" figure in ARCHITECTURE §2.9. The job costs 1 unit (P7-1).
- **Evidence is deterministic and timing-free.** In every one of the 38 runs, the hashed `inputs` and `outputs` contain no `ms` or `*Ms` field. Two runs of the same configuration give the same SHA-256. The runner sets `passed = (status == "pass")`, so an `inconclusive` or `fail` outcome is stored as evidence status fail. The budget-1 probe returns `inconclusive`, and `test_a_starved_budget…` covers it. The 0011 downgrade refuses while any orb job, evidence row or required kind exists, and both directions are tested.
- **The web side renders text only.** No `dangerouslySetInnerHTML`, `innerHTML`, `eval`, `new Function`, inline `style` or `process.env` appears in the scoped files. Links use `encodeURIComponent`. The orb submit goes through `apiSend('POST', '/api/v1/jobs')`, the CSRF-carrying helper. Neither `proxy.ts` nor the Caddyfile has changed since F-16.
- **The SDK uses no pickle, eval, exec, subprocess, file or network calls.** `qai/orb.py` imports math, time, collections.abc, functools, typing, numpy, scipy (integrate, optimize, special) and in-package modules only.
