MCP Sentinel

MCP Sentinel points at a Model Context Protocol endpoint, lists the server's tools, resources and prompts, and grades what it finds from A to F. The checks for tool poisoning, excessive scope, leaked secrets, rug pulls and missing auth are deterministic pattern and hash checks, with no language model in the scan path. This page records what the build produced, what passed, what was fixed on the way, and what is still open.

Open items

  • Automated SAST, secret scanning and config scanning have not run. The build recommends adding Semgrep, Gitleaks and OSV-Scanner or Trivy to CI.
  • No cloud deploy target was configured. The build was verified on the local docker-compose stack only.
  • Accepted advisory (ADR-016): registering an existing email returns a different response shape from a new one. Email verification is out of v1 scope. Per-IP rate limiting is the compensating control. Fix planned for v2.
  • Accepted advisory (ADR-016): the compare view renders the diff inline. The explicit ?compare= selector is deferred as a UX nicety.
  • Accepted advisory (ADR-016): the Drizzle email index differs cosmetically from the SQL migration. Behavior is correct because email is lowercased before insert.
  • Deferred (ADR-010): the has_webhooks domain signal. Version 1 has no inbound webhook surface. Re-evaluate if version 2 adds webhook-driven re-scans.
