Security audit: what was found

Findings from the three-pass audit (scan, remediate, re-scan). Remediated items were fixed in the build; the deferred item is accepted with the reason recorded.

IDSeverityFindingDisposition
F1MediumLogin and upload rate limiters keyed on the raw client IP without IPv6 normalization. An IPv6 client could rotate its address within a /64 to bypass the per-IP login limit.Remediated the limiter now applies IP key normalization. The startup validation error is gone.
F2MediumThe web tier used Node's default 16 KB header limit, so a Cookie header of 16 KB or more returned 431, while the API tier accepted it.Remediated the web tier runs with a 32 KB header buffer. A large cookie on the home page now returns 200.
F3LowRedis client settings caused a startup race in the rate-limit store, with noisy errors and a narrow window where a limiter was not ready.Remediated the offline queue is enabled, so boot-time commands wait for the connection.
F4LowA moderate advisory in postcss, pulled in transitively by next. It affects CSS stringification at build time only. The fix needs a breaking next downgrade.Deferred not reachable in the runtime server-rendered output. Revisit on the next minor upgrade of next.

Result after the re-scan: 0 critical, 0 high, 0 medium and 1 low residual item (F4), deferred with a recorded reason. The audit also confirmed signature verification before webhook processing, atomic stock decrement with a database check constraint, and 404 (not 403) on cross-customer lookups.

Open items

  • Live payments are unverified. Checkout and subscriptions return a contract-correct 503 without Stripe keys. Functional verification needs Stripe test keys and a passing run of smoke steps 6 to 8.
  • Order confirmation email is unverified. It needs a Resend key. Without one, the order completes and the email stays queued in the outbox.
  • The build runs on a local stack only. No external cloud target was provisioned.
  • At-rest encryption is delegated to the managed Postgres or host volume, and is marked as a note rather than a control in this build. Confirm provider encryption before production use.
  • Subresource integrity is not applied to first-party JavaScript (SEC-10). Next manages its own asset hashes. Revisit for SAQ A script attestation.
  • The PCI Attestation of Compliance and the operational controls (vendor management, access reviews) are an organizational process outside the codebase.
  • The product gallery shows token placeholders because no real product images were uploaded.
  • Admin product editing supports create and image upload only. Per-field editing is deferred, as recorded in the design gate.
  • Recorded deviation: ADR-012 pins Prisma to 6.19.3, while the architecture and spec documents name Prisma 7.
