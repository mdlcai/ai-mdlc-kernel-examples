ServiceHub

A multi-tenant IT service desk. Employees submit requests and incidents through a self-service portal and follow them to resolution. Agents triage, comment and resolve, with internal notes that requesters never see. Managers watch the team queue, SLA breaches and exportable reports. Each tenant's data is isolated in the database, and a requester who opens another employee's ticket or attachment gets a 404.

F1MediumThe file-type parser (v16) could loop forever on malformed input. It was reachable through the attachment upload path before the allowlist check.Remediated dependency removed. A dependency-free magic-byte sniffer now checks the 6 permitted types. Covered by the attachment upload, download and IDOR smoke checks.
F2Mediumpostcss below 8.5.10 (XSS through an unescaped </style> in stringify), pulled in transitively by Next.js.Accepted postcss only processes build-authored CSS, so there is no untrusted-input path in this build. Tracked until Next.js bumps its bundled postcss (ADR-12).

Open items

  • postcss (F2) stays open until Next.js ships a release that bundles a fixed postcss. The audit found no fix without downgrading Next.js to v9.
  • Encryption at rest is delegated to infrastructure (managed Postgres and volume encryption). It is not claimed as implemented in the application. The chosen KMS or volume encryption must be documented at deploy time.
  • Development secrets in docker-compose.yml must be replaced with production values from .env.example before any real deployment.
  • Attachment AV scanning is a pluggable interface with a quarantine flag. No antivirus engine is wired in. Magic-byte validation is in place.
  • The local build used the local-disk storage driver. The storage interface is abstracted for an S3-compatible driver (ADR-06).
  • SLA timers run on a 24/7 clock. A business-hours calendar is a documented extension point and is not built.
  • Email delivery was not exercised: Resend was stubbed. The HIBP breach check skips when offline and logs the skip.
  • UI end-to-end run: REPORT.md states that Playwright specs drive W1 to W4 through the UI. SMOKE-TEST.md describes the recorded run at the API contract level, and no Playwright result is recorded in the evidence.
