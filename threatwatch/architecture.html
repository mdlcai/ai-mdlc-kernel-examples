Architecture & site map

A multi-tenant SOC platform for small teams. Signed event batches are ingested, a Temporal worker runs detection rules and correlation, findings become triaged alerts, and alerts notify by email or signed webhook through outboxes. This page documents the runtime system, the request pipeline, and every screen in the web app.

03Core pipeline: event → alert → notification

The path a signed batch takes from an integration to an analyst's screen. Every side effect is written to an outbox in the same transaction as the state that caused it, then drained by a worker job.

Verify

POST /api/v1/ingest/:id. Body ≤ 256 KB; Standard Webhooks HMAC-SHA256 within ±300 s, constant-time. Any failure is the same 401.

Ingest

One transaction: receipt dedupe (replay → 200 {duplicate}), normalize, enrich (geo, intel, asset), insert events, create a pending batch, pg_notify. Returns 202 with per-event errors.

Detect

Workflow detect-<batchId>: claim batch with a conditional write, evaluate enabled rules (match clauses + windowed thresholds). A sweep picks up batches if Temporal was down.

Correlate

Group by shared entity (source IP, asset, indicator, user) within 30 min of event time. Create alert with evidence, risk score and MITRE technique.

Notify

Policies enqueue pending_emails / pending_deliveries in the alert's transaction. Drains send with capped backoff and a DLQ; escalation re-notifies.

Live

One LISTEN client fans notifications to that org's WebSockets. Payloads carry ids only; the client refetches through scoped REST.

Investigate

Alert detail joins evidence, rule version, source profile, asset, correlation siblings and timeline. Transitions are validated by the alert state machine.

Alert lifecycle

new → acknowledged → investigating → resolved or false_positive. Resolved and false-positive alerts can be reopened to investigating. An invalid transition returns 409 and the UI shows a conflict state.

09Data model

PostgreSQL 17 through Prisma 7. UUID v7 ids, TIMESTAMPTZ in UTC, enums as TEXT + CHECK, no floating-point columns. Every tenant table carries org_id with an index led by it.

10Security architecture

Controls that shape how pages and endpoints behave.

Sessions & CSRF

__Host-tw_session cookie (Secure, HttpOnly, SameSite), token stored as a SHA-256 hash. Every non-GET request needs a same-origin Origin; cross-origin mutations get 403 CSRF_ORIGIN.

Ingest authenticity

Per-integration secrets encrypted with AES-256-GCM. HMAC verified before parsing; replays are idempotent by message id; rate-limited per integration and per IP.

Outbound safety

Webhook URLs must be HTTPS and pass assertSafeUrl; delivery pins the resolved address to block DNS rebinding. Payloads are signed at insert time.

Error contract

RFC 9457 problem+json with code, detail, errors[] {field, code, message} and requestId. The web client attaches field errors to the offending control.

Headers & transport

Nonce-based CSP from proxy.ts, frame and content-type protections from Caddy. Local HSTS is max-age=0; production sets a real policy at its trusted origin.

Rate limits

Global 300/min/IP · login 10/min/IP + 5/min/email · register 5/h/IP · ingest 120/min/integration + 600/min/IP · search 60/min/user.
